# ChatFlow — Real-time Chat App

## Setup

### Backend

cd backend
npm install
cp .env.example .env # fill in your values
npm run dev # runs on port 5000

### Frontend

cd frontend
npm install
npm install socket.io-client
cp .env.local.example .env.local
npm run dev # runs on port 3000

## Open

http://localhost:3000
